# CLAUDE.md

## General rules
- Avoid code duplication and refactor code whenever possible.
- Code that is clear and readable by humans.
- Always comment functions and important parts of the code.
- Maintain the existing operation, except for those parts for which a modification is required.

## Architecture of the project
- For the architecture refer to the file ARCHITECTURE.md.

## Glossary
- For the terms used in the project and in our conversations refer to the file GLOSSARY.md.

## Code style
- Formatting is set by `.editorconfig` (4 spaces, LF, UTF-8, final newline).
- Language: comments, UI text, error messages and test names in Italian; identifiers in English.
